## 工夫したこと
- **構造体（struct）によるデータ管理**：
  タロカードの番号、名称、意味、選択肢（YES/NO等）を `struct TARTOR` で一元管理し、データのメンテナンス性と拡張性を高めました。
- **重複なしのランダム抽牌アルゴリズム**：
  「過去・現在・将来」などの複数枚カードを引くモードにおいて、`do-while` 述語と配列チェックを用いて同じカードが重複して選ばれない仕組みを実装しました。
- **`time` 関数による真のランダム性**：
  `srand((unsigned int)time(NULL));` を導入し、プログラムを実行するたびに異なる時間シードを生成することで、毎回異なるランダムなカード結果が得られるようにしました。
- **入力ミス（バリデーション）の防止**：
  メニュー選択や数値入力において、想定外の数字や英字、不正な文字列が入力された際にプログラムが無限ループや誤作動を起こさないよう、バッファクリア（`getchar()`）とエラーハンドリングを強化しました。
- **モジュール化とコードの可読性**：
  画面描画、カード生成、ロジック処理などを各関数に分割し、詳細なコメントを添えることで、将来的な保守やチームでの共有をしやすいように工夫しました。
